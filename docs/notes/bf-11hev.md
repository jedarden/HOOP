### 4. Log File Naming Pattern ✅
**Finding:** Log files follow a consistent naming pattern with descriptive names and ISO 8601 timestamps.

**Naming Pattern:**
```
<descriptive_name>_<timestamp>.log
```

**Components:**
- **Descriptive name:** Derived from test type or auto-generated from command
- **Timestamp:** ISO 8601 format in UTC (`YYYYMMDDTHHMMSSZ`)
- **Extension:** `.log`

**Examples:**
```

test_basic_load_config_20260802T171150Z.log
Test_passed_20260802T173931Z.log
hoop_cli_status_test_20260802T170104Z.log
```

## Wrapper Script Behavior

### Input/Output Capture
The `run-with-log.sh` script provides comprehensive output capture:

1. **Dual-stream capture:** Both stdout and stderr are captured to the log file
2. **Exit code preservation:** Original command's exit code is returned
3. **Environment variables:** Captured output is exported for potential use:
   - `HOOP_CAPTURED_STDOUT`
   - `HOOP_CAPTURED_STDERR`
   - `HOOP_CAPTURED_LOG_FILE`
   - `HOOP_CAPTURED_EXIT_CODE`

### Auto-naming Feature
When using `--auto` flag, log names are generated by `bin/generate-test-log-name.sh`:
- Derives descriptive name from command
- Defaults to `logs/` directory if it exists
- Prints generated path to stderr for visibility
