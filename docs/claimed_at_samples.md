## Format Analysis

### Consistent Pattern Across All Sources

**Structure:** `YYYY-MM-DDTHH:MM:SS[.NNNNNNNNN]±HH:MM`

**Components:**
- **Date:** `YYYY-MM-DD` (ISO 8601 date)
- **Separator:** `T` (literal 'T' between date and time)  
- **Time:** `HH:MM:SS` (24-hour format)
- **Fractional seconds:** Optional `.NNNNNNNNN` (0-9 digits, all observed in production use 9)
- **Timezone:** Either `Z` (UTC) or `±HH:MM` (offset from UTC)

### Real Production Format vs Test Coverage

**Production Reality (from events.jsonl):**
- Always uses 9-digit fractional seconds (nanosecond precision)
- Always uses explicit `+00:00` timezone offset (never just `Z`)
- Generated automatically by NEEDLE workers
- No variation in format across events or workers

**Test Coverage (from claimed_at_parsing.rs):**
- Covers broader RFC3339 specification
- Tests multiple fractional precisions (0-9 digits)
- Tests both `Z` and offset notation
- Tests edge cases (leap years, boundaries, invalid formats)

## Data Flow Context

**How claimed_at Values Are Generated:**

1. **NEEDLE Worker Action:** When a NEEDLE worker claims a bead, it emits a Claim event to `events.jsonl`
2. **Timestamp Assignment:** The worker assigns the current time in RFC3339 format with nanosecond precision
3. **HOOP Processing:** HOOP daemon reads events.jsonl and processes Claim events via `update_fleet_from_event()`
4. **Validation:** The `sanitize_timestamp()` function validates the RFC3339 format (supervisor.rs:1084-1102)
5. **Storage:** Sanitized timestamp stored in `collision_index` table via `CollisionIndexEntry` struct
6. **Fallback:** If timestamp is empty or invalid, `Utc::now().to_rfc3339()` is used as fallback

**Source Code References:**
- **Parser:** `hoop-daemon/src/supervisor.rs:1084-1102` (`sanitize_timestamp()`)
- **Usage:** `hoop-daemon/src/supervisor.rs:1172` (called in `update_fleet_from_event()`)
- **Storage:** `hoop-daemon/src/fleet.rs` (CollisionIndexEntry struct, collision_index table)
- **Tests:** `hoop-daemon/tests/claimed_at_parsing.rs` (comprehensive edge case coverage)
